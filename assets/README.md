# Folder Assets

Folder ini digunakan untuk menyimpan foto, gambar kegiatan, ilustrasi, dan dokumen pendukung yang memang boleh dipublikasikan di E-Portfolio PPG.

## Nama berkas yang direncanakan

- `foto-profil.jpg` — foto profil pada halaman beranda (pastikan format dan nama berkas sesuai dengan yang dirujuk di HTML).
- `foto-kegiatan-01.jpg`, `foto-kegiatan-02.jpg` — dokumentasi kegiatan yang aman dipublikasikan.
- `modul-ajar.pdf`, `lkpd-ct.pdf`, dan berkas lain — artefak pembelajaran yang memang boleh diakses publik.

## Cara mengunggah

1. Buka folder `assets` di repository GitHub.
2. Pilih **Add file → Upload files**.
3. Pilih foto/dokumen dari perangkat.
4. Pastikan nama berkas cocok dengan tautan di halaman HTML.
5. Isi pesan commit lalu pilih **Commit changes**.

## Catatan privasi

Repository portofolio ini dapat diakses publik. Jangan unggah data pribadi peserta didik, nilai/rekap identitas, dokumen internal, atau berkas yang hanya boleh diakses pemilik. Berkas yang perlu tetap privat simpan di lokasi privat dan jangan menautkannya ke halaman publik.
